# Arnav's California Roadbook

Static trip-planning website for September 18–October 10, 2026, including Bay
Area weekends and evenings plus the October 3–8 Sierra-to-sea road trip.

## Run locally

```bash
cd /Users/chaarnav/california-trip-site
python3 -m http.server 8765
```

Open `http://localhost:8765`.

The site includes weekend itineraries, filterable local ideas, direct Google
and Apple Maps links, a day-selectable road-trip map, and the Highway 1 backup
route toggle.
