# Arnav's California Loop

Static trip-planning website for October 3–8, 2026.

## Run locally

```bash
cd /Users/chaarnav/california-trip-site
python3 -m http.server 8765
```

Open `http://localhost:8765`.

The site stores reservation checkboxes, packing progress, the Highway 1 route
choice, and the Three Rivers Airbnb address in browser local storage.
